KOMGRUP — PIPER TTS + LIVE BROADCAST WAV V1

Google Cloud TTS DIHAPUS. Piper berjalan server-side tanpa billing/kartu.

FLOW
Admin TTS -> /api/tts/synthesize -> Piper -> WAV -> existing Web Audio MediaStreamDestination -> existing PeerJS/WebRTC Broadcast Audio.

WAV TIDAK dikonversi ke MP3.

WINDOWS
1. python --version
2. python -m pip install --upgrade pip
3. python -m pip install piper-tts==1.7.0
4. python -m piper.download_voices id_ID-news_tts-medium --data-dir .\piper-voices
5. python -m piper -m id_ID-news_tts-medium --data-dir .\piper-voices -f test.wav -- "Halo, ini tes KomGrup."

ENV
PIPER_PYTHON=python
PIPER_DATA_DIR=./piper-voices
