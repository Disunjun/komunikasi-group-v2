KOMGRUP — PIPER TTS WAV V2

1. Piper sudah terpasang:
   python -m pip install piper-tts==1.7.0

2. Voice Bahasa Indonesia:
   id_ID-news_tts-medium

3. Model lokal berada di ROOT project:
   id_ID-news_tts-medium.onnx
   id_ID-news_tts-medium.onnx.json

4. server.js V2 default:
   PIPER_DATA_DIR=.
   Jadi model ROOT project dapat langsung ditemukan.

5. Opsional .env lokal:
   PIPER_DATA_DIR=.
   PIPER_VOICE=id_ID-news_tts-medium
   PIPER_TIMEOUT_MS=30000

6. Jalur TTS:
   Teks -> Piper -> WAV -> AudioContext/MediaStreamDestination -> PeerJS/WebRTC Broadcast.
   Tidak ada konversi WAV ke MP3.

7. TEST:
   Klik 1x = mulai live.
   Klik 2x = stop live.
   TEST hanya mengikuti target Group/Channel; Hari/Jam diabaikan.

8. SCHEDULE:
   Hari checkbox + satu Jam HH:MM.
   Tidak ada jam selesai.
   Tidak ada tombol Mulai Siaran.
   TTS/audio diputar satu kali ketika waktu tercapai.

9. Jangan upload ke GitHub:
   *.onnx
   *.onnx.json
   .env
   credential/secret apa pun

10. Untuk production, model Piper harus tersedia di runtime server.
    Jangan mengandalkan model yang hanya ada di PC lokal.
